# Pennywise — Student Expense Tracker

A responsive React expense tracker for students, built with Vite, React Router, Recharts and Lucide icons.

## Features
- Dashboard with balance, income, expenses, budget remaining and charts
- Add income/expense transactions with categories and dates
- Search, filter, sort, delete and export transactions to CSV
- Category budgets and adjustable overall monthly budget
- Reports with spending breakdown and insights
- Settings, profile name, reminders toggle and demo-data reset
- Responsive sidebar, hover states, chart tooltips and localStorage persistence

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite, usually http://localhost:5173.

## Notes
This is a front-end demo. Data is stored in this browser's localStorage; there is no authentication or bank integration. Dashboard charts include illustrative daily chart data while totals and transaction lists are based on the current local transaction data.
